# ハノイの塔（Tower of Hanoi）

円盤を動かして遊べる「ハノイの塔」のブラウザアプリです。段数を変えたり、解答のアニメーションを確認したりできます。

**アプリを開く：** https://handson-matsu.github.io/tower-of-hanoi/

> 公開URLは、GitHub Pagesを設定して公開した後に利用できます。

## 遊び方

3本の柱のうち、最初の柱に積まれた円盤を、すべて別の柱へ移動させるパズルです。

1. 1回に移動できる円盤は1枚だけです。
2. 各柱の一番上の円盤だけを動かせます。
3. 大きな円盤を小さな円盤の上に置くことはできません。

なるべく少ない手数で完成させてみましょう。

## 主な機能

- 円盤の段数を3〜64段に変更
- 移動回数と理論上の最小移動回数を表示
- 解答アニメーションの再生
- 通常・10倍・100倍速の切り替え
- 解答再生の一時停止・再開
- 自力クリア時の演出と効果音
- 解答を見て終了した場合は、自力クリアとは異なるメッセージを表示

## 数学的な背景

円盤が **n** 枚のとき、最小移動回数は **2^n − 1** 回です。

| 円盤の枚数 | 最小移動回数 |
| ---: | ---: |
| 3 | 7 |
| 4 | 15 |
| 5 | 31 |
| 10 | 1,023 |
| 64 | 18,446,744,073,709,551,615 |

64枚の円盤を1秒に1回のペースで移動し続けても、約5,845億年かかります。アプリの高速再生でも、膨大な手数を実感できます。

## 教材としての活用

規則性の発見、数列・漸化式、数学的帰納法、指数関数的な増加などの題材として活用できます。

本アプリは、ChatGPTとの対話を通して、基本的なパズルから段数変更、解答確認、高速再生、クリア演出などを段階的に追加して制作したものです。AIを利用した教材開発のモデルケースとしても紹介できます。

## 動作環境

HTML・CSS・JavaScriptによる単一ファイルのアプリです。外部ライブラリやサーバーは不要で、`index.html` をブラウザで開いて利用できます。スマートフォンやタブレットでは、ブラウザやファイルの開き方によって動作が異なる場合があります。
